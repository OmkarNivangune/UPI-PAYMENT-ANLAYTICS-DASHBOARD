# UPI-PAYMENT-ANLAYTICS-DASHBOARD📊

## 📌 Project Overview
An interactive Power BI dashboard developed to analyze UPI transactions, payment success and failure rates, transaction trends, response times, and payment reliability.

Python and Pandas were used for data cleaning and preprocessing, while Power BI was used for data visualization, KPI reporting, and performance analysis.

## 🛠️ Tools & Technologies
- **Python & Pandas:** Data cleaning and preprocessing
- **Power BI:** Interactive dashboard development
- **DAX:** KPI calculations and analytical measures
- **Power Query:** Data transformation

## 📊 Dashboard Pages

1. **Overall Performance Analysis:** Transaction count, transaction amount, payment status, and performance trends.
2. **Payment Failure Analysis:** Failure reasons, failure codes, failed transaction values, and response times.
3. **UPI Reliability & Performance:** Transaction status, application performance, network analysis, and response times.
4. **Trend & Performance Analysis:** Transaction trends, success rates, monthly values, and network performance.

## 🔄 Project Workflow
Raw Dataset → Python & Pandas Data Cleaning → Cleaned Dataset → Power BI → DAX Measures → Interactive Dashboards → Business Insights

## 🎯 Key Objectives
- Analyze transaction success and failure patterns.
- Identify common payment failure reasons.
- Monitor transaction trends and response times.
- Compare UPI application and network performance.
- Support data-driven decision-making.

## 💡 Key Skills Demonstrated
Python | Pandas | Power BI | DAX | Power Query | Data Cleaning | Data Visualization | KPI Analysis | Business Intelligence

## 📌 Conclusion
This project demonstrates how Python and Power BI can transform raw UPI transaction data into meaningful insights to evaluate payment performance, identify failure patterns, and understand transaction reliability.
